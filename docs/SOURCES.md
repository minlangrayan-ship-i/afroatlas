# Sources, licences et instantanés

Import initial : 4 octobre 2026. Les millésimes des sources ne sont pas assimilés à la date de collecte.

- Wikidata : API `wbsearchentities` avec pagination configurée (premier lot limité à 5 candidats par espèce), puis `Special:EntityData/QID.json`. Sélection P225 scientifique exacte ; libellés et alias localisés uniquement par langue, statut documented. Données structurées CC0. QID, numéro de révision et pointeur JSON sont conservés. [Documentation](https://www.wikidata.org/wiki/Wikidata:Data_access).
- Wikimedia Commons : `action=query&prop=imageinfo&iiprop=url|extmetadata&iiurlwidth=960`. Chaque photo possède page source, artiste, titre, licence exacte, URL de licence, attribution, dimensions et transformations. Téléchargement autorisé puis WebP 400/960, orientation EXIF, sans recadrage. Les fichiers dérivés CC BY-SA restent sous leur licence. Les métadonnées à balises HTML sont converties en texte avant publication. [Réutilisation](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia).
- Open Food Facts : `/api/v2/search` pour filtres catégories gingembre et curcuma, 5 références maximum par catégorie. L’API v2 de recherche structurée est conservée car cette fonction n’est pas disponible dans v3 selon la documentation consultée. Aucun appel pendant la consultation. User-Agent identifiable, cache, quotas. Jeu identifiable redistribué sous ODbL / Database Contents License. Aucun média d’emballage importé. Pas de rapprochement avec les espèces sans preuve d’étiquette. [Documentation et différences v2/v3](https://openfoodfacts.github.io/documentation/docs/Product-Opener/api/), [licences](https://openfoodfacts.github.io/documentation/docs/Product-Opener/api/tutorials/license-be-on-the-legal-side/).
- geoBoundaries gbOpen ADM1 : CMR 2016 (10), CIV 2016 (14), MAR 2017 (12), SEN 2019 (14). Les noms sont ceux des objets ADM1 du jeu ; Côte d’Ivoire présente des districts à ce niveau, pas une liste de 31 régions. Contrôle structurel : ISO, ADM1, noms présents et nombre cohérent avec métadonnées. Source, identifiant, date et géométrie simplifiée sont conservés. Licences déclarées par fichier : CMR CC BY 3.0, CIV CC BY 4.0, MAR ODbL 1.0, SEN CC BY 3.0 IGO. La licence du jeu agrégateur ne remplace pas les obligations sous-jacentes. [API](https://www.geoboundaries.org/api.html).
- Natural Earth : admin 0 110m v5.1.2, dépôt officiel `nvkelso/natural-earth-vector`. Domaine public ; représentation générale non autoritative. Les territoires contestés suivent la source sans déclaration de rattachement culturel. Maurice peut ne pas être dessinée à cette échelle ; la liste accessible reste complète. [Conditions](https://www.naturalearthdata.com/about/terms-of-use/).

GBIF et publications ethnobotaniques sont des pistes d’enrichissement, pas des sources déjà importées. Aucun nom inventé par IA ne sert de preuve. Aucun catalogue privé n’est scrapé.

## Redistribuer les données

Le code peut être réutilisé selon sa licence. Les données sont un ensemble de collections avec licences distinctes : les libellés Wikidata sous CC0, les photos sous leurs licences individuelles, Open Food Facts sous ODbL/DbCL, la géographie sous les licences déclarées. La séparation technique de fichiers n’exonère pas des obligations des ensembles dérivés. Les métadonnées et géométries MAR sous ODbL sont redistribuées accessibles, et toute base dérivée relevant de cette licence doit conserver le partage à l’identique. Aucune prétention de conformité juridique générale n’est faite.

Les liens de sources et crédits complets sont accessibles sur `/sources/` et chaque fiche. L’instantané OFF, les assertions et les géographies sont téléchargeables et dans le dépôt public.
